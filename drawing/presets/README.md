# Excalidraw 手绘预设

直接在任务单中写预设的中文名。创建新图时参照对应样板的 appState、线条、填充和文字外观，按题目重新构图。每张样板可独立打开编辑；锁定的矩形是底纸。中文说明采用清晰的无衬线字体，手绘感来自轮廓与笔触。

| 名称 | 配色与笔触 | 构图方式 |
|---|---|---|
| [白板速写](whiteboard.excalidraw) | 白底、炭蓝墨线、蓝色强调，roughness 1 | 对象直接摆在画布上，用短箭头和就近文字讲清主线；局部手划线强调标题 |
| [纸上讲解](notebook.excalidraw) | 奶油纸底、深棕轮廓、青绿水路、赭橙批注，roughness 1 | 用对象轮廓描绘机制，在值得解释的部位加小物件和引线注释 |
| [手绘线框](wireframe.excalidraw) | 白底、石墨轮廓、浅灰面板、砖红标记，roughness 1 | 对齐框架、统一间距，保留轻微笔触；用短批注标出作用位置 |

设计参考为 [Capable 的思维导图、带图像流程图和线框样例](https://help.gocapable.com/diagrams/excalidraw-examples.html) 及 [Excalidraw 公共素材库](https://libraries.excalidraw.com/)。本地样板中的对象均以原生元素重新绘制。
