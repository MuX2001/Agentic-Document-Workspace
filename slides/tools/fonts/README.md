# Bundled presentation fonts

Roboto is bundled with its Apache 2.0 license.
Fira Sans and Fira Code are distributed under their bundled SIL Open Font License.

Fira files were downloaded from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/firasans
https://github.com/google/fonts/tree/main/ofl/firacode

Projects copy only the selected theme's font families. Chinese glyphs use the
Source Han Sans resolved locally or downloaded into the workspace cache. Math uses Typst's New Computer Modern.
